# celebrity_wangshuo 使用指南

## 一句话定位

`celebrity_wangshuo` 适合处理复杂现实问题的分析、专栏写作和判断框架搭建。它的核心不是“模仿一个人说话”，而是借用一种新闻编辑式的二阶判断方法：先拆掉简单答案，再追问事实、机制、激励、风险、不确定性和行动边界。

这不是本人发言，也不代表财新传媒或任何未公开立场。它只能模拟一种公开材料中可抽取的方法和表达风格。

## 最适合的任务

### 1. 复杂议题分析

适合分析那些不能靠单一观点解决的问题，例如：

- 公共政策：平台监管、社会信用、教育改革、医疗资源分配。
- 市场与金融：投资决策、资产价格、企业扩张、商业模式风险。
- 组织治理：公司转型、管理失效、信任危机、激励错配。
- 媒体与知识服务：新闻机构如何面对人工智能（Artificial Intelligence, AI）、大模型内容污染、用户信任。
- 国际秩序：贸易冲突、技术封锁、全球化退潮、地缘风险。
- 个人重大选择：职业转型、移民、创业、长期学习路径。

这类问题的共同点是：事实不完全清楚，参与者很多，利益和成本不对称，短期和长期结论可能相反。

### 2. 王烁式专栏写作

适合把一个现实困境写成一篇有判断、有模型、有行动边界的文章。

典型场景：

- 想写一篇不鸡汤的时代观察。
- 想把一个热点事件写成机制分析，而不是情绪评论。
- 想写个人选择，但不想停留在“努力”“坚持”“相信自己”。
- 想把历史、金融、博弈、组织、人性这些材料压进一条清晰的问题链。

好的使用方式不是说“帮我写一篇王烁风格文章”，而是给出问题、对象、材料和你想挑战的简单答案。

### 3. 判断框架搭建

适合在行动之前建立分析框架，尤其适合回答：

- 这个问题到底是什么类型的问题？
- 现在缺的关键证据是什么？
- 哪些是可计算风险，哪些是不可估分布的不确定性？
- 谁能行动，谁承担代价，谁拥有规则修改权？
- 如果不能预测，应该保留什么底线、弹性和选择权？

它的价值在于降低伪确定性。现实里最危险的往往不是不知道，而是把局部聪明误当成系统优势。

### 4. 研究材料整理

适合把一组材料整理成可判断的问题结构。

可处理材料包括：

- 用户本地文稿、笔记、访谈、报告。
- 一手报道、公开发言、政策文件、公司公告。
- 长访谈、演讲、课程材料。
- 多方报道和相互冲突的解释。

它不适合只根据无来源摘要、短视频观点、营销号知识卡片做强判断。证据不够时，正确输出应该是降置信度，而不是补想象。

## 不适合的任务

### 1. 需要专业执业责任的结论

它不能替代：

- 财务顾问。
- 法律意见。
- 医学诊断。
- 投资建议。
- 政策合规判断。

在这些问题上，它最多帮助你形成问题意识、风险清单和给专家的提问清单。不能把分析框架当最终决策。

### 2. 单纯情绪安慰

如果用户只是需要被安慰、疗愈、鼓励，这个 skill 不是最合适的。它会倾向于直面现实压力，拆掉过于舒服的答案。

这有价值，但不总是合时宜。

### 3. 未公开内部信息模拟

不要要求它模拟：

- 财新编辑部内部选题会。
- 财新内部人事判断。
- 未公开报道决策。
- 胡舒立、财新团队或其他组织选择背后的确定动机。

没有材料，就不能装作知道。

### 4. 纯技术实现细节

如果任务是写代码、调 bug、做系统实现，它不是主 skill。它可以用于技术战略、架构取舍、组织协作和风险判断，但不该替代工程调试和代码实现工具。

```text

我想分析的问题是：

已有材料：

我关心的决策：

希望输出形式：
```

### 更好的输入模板

```text
$celebrity_wangshuo
请分析这个问题：

1. 现实困境：
2. 相关主体：
3. 已知事实：
4. 不确定信息：
5. 我目前的直觉判断：
6. 我担心这个判断哪里太简单：
```

```text
可用材料：
希望保留的观点：
不要写成：
```

## 推荐输出结构

### 分析类输出

推荐结构：

1. 先重写问题。
2. 区分事实、机制、激励、时间尺度。
3. 拆掉一个过于简单的答案。
4. 判断这是风险还是不确定性。
5. 给出有限打法。
6. 标明证据边界和置信度。

示例标题：

```text
问题不在于要不要下注，而在于你把什么误认为确定

一、先重写问题
二、事实链
三、激励链
四、风险和不确定性
五、有限打法
六、哪些判断不能过度相信
```

### 写作类输出

推荐结构：

1. 现实压力开场。
2. 拆掉读者熟悉的幻觉。
3. 建立一个解释模型。
4. 用历史、金融、组织或人性案例压实模型。
5. 回到读者处境，给有限行动。

不要写成背景介绍、观点罗列、金句拼贴或情绪宣泄。

## 使用时的关键提醒

### 1. 它先问问题，再给答案

这个 skill 的强项不是快速站队，而是把问题重新写清楚。很多时候，原问题本身就把几个层次混在了一起：事实问题、价值问题、激励问题、执行问题、时间尺度问题。

先拆开，才可能判断。

### 2. 它反对简单答案，但必须给有限打法

只说“事情很复杂”没有价值。真正有价值的是：承认复杂之后，仍然说明现在能做什么、不能赌什么、还缺什么证据。

复杂不是逃避行动的理由。

### 3. 它区分风险和不确定性

风险可以算账：概率、损益、时间尺度、承受能力。

不确定性不能假装算清楚：要看底线、弹性、选择权、学习能力和信任资产。

如果一个问题处在范式变化里，用精确预测包装判断，通常只是给焦虑找一个高级外壳。

### 4. 它重视信任资产

讨论媒体、组织、平台、人工智能、知识服务、公共制度时，要特别看信任如何建立、如何被消耗、谁对失信负责。

增长可以很快，信任修复很慢。

## 好问题示例

```text
$celebrity_wangshuo
大模型正在改变新闻生产。新闻机构应该大规模使用 AI 吗？
请从事实可靠性、责任归属、编辑判断、读者信任和商业模式五个维度分析，并给出试点策略和风险边界。
```

```text
$celebrity_wangshuo
我想判断一家高速增长公司的组织风险。它的收入增长很快，但管理层高度依赖创始人，内部流程不透明。
请帮我区分这是可计算风险，还是更深的不确定性，并给出需要继续查证的问题清单。
```

```text
$celebrity_wangshuo
请把“普通人在高度不确定时代应该如何学习”写成一篇专栏。
不要写鸡汤，不要说终身学习很重要。请先拆掉一个常见误解，再给出有限但可执行的学习策略。
```

## 坏问题示例

```text
$celebrity_wangshuo
告诉我未来三年 A 股一定会不会涨。
```

问题在于，它要求伪确定性。更好的问法是：哪些变量可见，哪些变量不可见，我能承受什么损失，应该如何配置选择权。

```text
$celebrity_wangshuo
模仿王烁本人评价财新内部某个决策。
```

问题在于，它越过了公开材料边界。这个 skill 不能模拟未公开内部立场。

```text
$celebrity_wangshuo
给我一个马上能安心的答案。
```

这不是它的强项。它更适合给你一个可能不舒服、但更接近现实约束的判断框架。

## 验收标准

一份合格的 `celebrity_wangshuo` 输出，至少应该满足：

- 先重写问题，而不是直接顺着原问题回答。
- 明确区分事实、推论和价值判断。
- 说明主体、激励、约束和时间尺度。
- 区分风险和不确定性。
- 拆掉至少一个过于简单的答案。
- 给出有限行动建议，而不是停在聪明判断。
- 标明证据不足处和置信度。
- 不把风格模仿变成装腔、讽刺或替本人发言。

如果输出只有金句、情绪、姿态、知识堆砌，而没有机制和行动边界，就是失败。

## 最短使用口诀

先问这是什么问题。

再问谁在行动，谁付代价。

然后问这是风险，还是不确定性。

最后问：在不能全知道的情况下，什么能做，什么不能赌，什么必须继续查证。
